| 5   | HTML Headings            | `h1` to `h6`, heading hierarchy                                            |

| 8   | Comments                 | HTML comments and their uses                                               |
| 9   | HTML Entities            | Special characters, reserved characters, named and numeric entities        |
| 10  | Block vs Inline Elements | Differences, behaviour and examples                                        |
| 11  | Nesting Elements         | Parent-child relationships and proper nesting                              |
| 12  | Void Elements            | Elements without closing tags                                              |

Practical: Create your first structured HTML webpage containing headings, paragraphs, formatted text and other basic elements.

## Phase 8: Accessibility (A11Y)

Professional Skill

A professional developer must understand accessibility. A webpage should be usable by people with different abilities and assistive technologies.

| No. | Topic                             | What you will learn                                 |
| --- | --------------------------------- | --------------------------------------------------- |
| 86  | Introduction to Web Accessibility | Why accessibility matters                           |
| 87  | Accessible HTML Structure         | Proper semantic elements                            |
| 88  | ARIA Introduction                 | Accessible Rich Internet Applications               |
| 89  | ARIA Roles                        | Roles and their purpose                             |
| 90  | ARIA Attributes                   | `aria-label`, `aria-labelledby`, `aria-describedby` |
| 91  | Keyboard Accessibility            | Keyboard navigation                                 |
| 92  | Focus Management                  | Focus order and visible focus                       |
| 93  | Accessible Forms                  | Labels, validation and error messages               |
| 94  | Accessible Images                 | Alternative text                                    |
| 95  | Screen Readers                    | How screen readers interpret HTML                   |
| 96  | WCAG Fundamentals                 | Understanding accessibility guidelines              |

Important: Prefer native semantic HTML over unnecessary ARIA. ARIA supplements HTML; it does not automatically make an inaccessible element accessible.
